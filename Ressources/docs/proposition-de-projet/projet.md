# Le projet

### 1. Site web pour le Bistrot

Créer le premier site web du Bistrot d'El Dorado. Il présente l'ensemble des activités du lieu, et donne toutes les informations pertinentes pour les visiteurs et le référencement sur les moteurs de recherche.

### 2. Préciser l'image de marque

Le site web doit être conçu en accord avec l'image de marque de l'entreprise.  Le Bistrot dEl Dorado ayant une image de marque imprécise, nous tenterons de la définir.

Cette définition ne sert pas uniquement au site. Elle sera conçue pour être réutilisée sur tous les supports de communication : réseaux sociaux, affiches imprimées, publicités.

### 3. La newsletter existante

Une newsletter est déjà existante avec environ 600 destinataires.  C'est une base solide qu'on doit intégrer au nouveau site et au nouveau système.

### 4. Présence unifiée

LE BED existe déjà sur Facebook et Instagram. Nous porterons l'attention nécessaire pour unifier l'image de l'entreprise en accord avec le nouveau site web. Il sera aussi important d'inscrire le BAD sur d'autres plateformes d'intérêt, entre autre Google Business Profile. Le lieu cumulant plusieurs activités (bar, restaurant, concerts, poste), la fiche google doit les présenter clairement pour être trouvée sur chacune d'elles.
