# Le projet

### 1. Site web pour le Bistrot

Créer le premier site web du Bistrot d'El Dorado. Il présente l'ensemble des activités du lieu, publie l'agenda des concerts et donne les informations pratiques utiles aux visiteurs.

### 2. Préciser l'image de marque

Formaliser une définition précise de l'image de marque : nom, ton, ligne éditoriale, textes de référence, nom de domaine. Cette définition ne sert pas uniquement au site. Elle est conçue pour être réutilisée sur tous les supports de communication : réseaux sociaux, affiches imprimées, publicités.

### 3. La newsletter existante

Une newsletter est déjà existante avec environ 600 destinataires.  C'est une base solide qu'on doit intégrer au nouveau site et au nouveau workflow.

### 4. La fiche d'établissement Google

Créer et optimiser la fiche Google. Le lieu cumulant plusieurs activités (bar, restaurant, concerts, poste), la fiche doit les présenter clairement pour être trouvée sur chacune d'elles.
